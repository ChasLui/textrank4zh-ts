🛠️ 技术特性

TextRank4ZH-TS 是用 TypeScript 重写的 TextRank 算法实现，专门针对中文文本优化，提供完整的浏览器支持和现代化的开发体验。

支持函数式错误处理、主线程调度、多种运行模式，确保在各种环境下都能稳定高效运行。

TypeScript Web Workers ES2020+ 零外部依赖 函数式编程 PageRank 算法
